# Sorry, I Heard That Wrong

Entry for the [make.fun bounty](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729): a program that writes the one-line apology a smart speaker gives its owner after mishearing them to `/output/entry.txt`.

## The apology

> Sorry — I heard 'wake me at seven' as 'wake me in heaven.' I checked twice and can neither confirm nor deny where you are.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, Python 3.13, standard library only. The program writes exactly
one line (122 characters) to `/output/entry.txt`.
